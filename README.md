# КЕЛО — Frontend интернет-магазина

Готовый адаптивный frontend интернет-магазина изделий из дерева на **TypeScript + React**. Структура страниц построена по мотивам контентной модели сайта-референса `sdelanoartel.com`, но дизайн, тексты, товарная модель и фирменная зелёно-белая стилистика разработаны для КЕЛО.

## Что реализовано

- главная страница с hero-блоком, категориями, преимуществами, промоблоками, популярными товарами, историей производства, блогом и подпиской;
- каталог с категориями, поиском, сортировкой и фильтрами по цене, материалу и наличию;
- подробная карточка товара с галереей, характеристиками, вкладками, количеством, корзиной, избранным и похожими товарами;
- акции;
- индивидуальное производство и форма расчёта;
- блог, фильтрация статей и отдельная страница статьи;
- бренды;
- доставка и оплата;
- страница о производстве;
- контакты и форма обратной связи;
- поиск;
- корзина с пересчётом количества и итоговой суммы;
- оформление заказа;
- избранное;
- демонстрационный личный кабинет;
- политика конфиденциальности и оферта-заглушка;
- страница 404;
- адаптация для desktop, tablet и mobile;
- локальное сохранение корзины, избранного и demo-профиля;
- mock-сервисы, которые имитируют будущий backend.

## Технологии

- React 18
- TypeScript
- Vite
- React Router
- TanStack Query

- CSS без UI-фреймворка

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Работа без backend

По умолчанию используется mock-режим:

```env
VITE_USE_MOCKS=true
```

Товары, категории, статьи, бренды и акции находятся в:

```text
src/data/mockData.ts
```

Корзина, избранное и demo-авторизация хранятся в `localStorage` с помощью Zustand Persist.

## Подключение backend

После появления backend измените `.env`:

```env
VITE_API_BASE_URL=https://api.example.ru/api
VITE_USE_MOCKS=false
```

Точки интеграции уже вынесены в отдельные файлы:

```text
src/api/client.ts
src/services/catalogService.ts
src/services/orderService.ts
src/services/feedbackService.ts
```

Предлагаемый контракт API описан в [docs/BACKEND_API.md](docs/BACKEND_API.md).

## Добавление изображений заказчика

Папки уже созданы:

```text
public/images/products
public/images/categories
public/images/banners
public/images/blog
public/images/brands
```

После копирования файлов пропишите путь в `src/data/mockData.ts`, например:

```ts
images: [
  '/images/products/reznoe-okno-1.jpg',
  '/images/products/reznoe-okno-2.jpg',
]
```

Пока путь не указан, компоненты показывают зелёно-белые фирменные заглушки. Это позволяет разрабатывать весь интерфейс до подготовки изображений.

## Основные маршруты

| Маршрут | Страница |
|---|---|
| `/` | Главная |
| `/catalog` | Каталог |
| `/catalog/:slug` | Карточка товара |
| `/promotions` | Акции |
| `/custom-order` | Изделия на заказ |
| `/blog` | Блог |
| `/blog/:slug` | Статья |
| `/brands` | Бренды |
| `/delivery` | Доставка и оплата |
| `/about` | О компании |
| `/contacts` | Контакты |
| `/search?q=...` | Поиск |
| `/favorites` | Избранное |
| `/cart` | Корзина |
| `/checkout` | Оформление заказа |
| `/account` | Личный кабинет |
