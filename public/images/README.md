# Изображения проекта КЕЛО

Поместите изображения заказчика в соответствующие папки:

- `products` — фотографии товаров;
- `categories` — обложки категорий;
- `banners` — баннеры главной страницы и акций;
- `blog` — изображения статей;
- `brands` — логотипы брендов.

После добавления файлов укажите пути в `src/data/mockData.ts`.
Пока путь отсутствует, интерфейс автоматически показывает фирменную зелёно-белую заглушку.
